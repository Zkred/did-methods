Initial release: did:cid resolution as a did-resolver plugin. A thin client for an Archon gatekeeper's standards-conformant `/1.0/identifiers/{did}` endpoint, with `versionTime`/`versionSequence` query passthrough and `/data` / `/registration` dereferencing. With this package the monorepo covers all three DIF Recommended DID methods in one resolver.
